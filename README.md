# Paradise Nursery Shopping Application

Paradise Nursery is an online plant shopping application where users can browse houseplants, view plant details, add plants to a shopping cart, manage quantities, and view the total cost.

## Features

- Browse houseplants by category
- View plant names and prices
- Add plants to the shopping cart
- Increase and decrease quantities
- Remove plants from the cart
- View total cart amount
- Continue shopping
- Checkout option

## Technologies Used

- React
- JavaScript
- Redux Toolkit
- CSS
